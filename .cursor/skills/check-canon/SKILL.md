# Check canon

Проверь сущности на соответствие `meta/CANON_POLICY.md` и `meta/RULES.md`.

1. Запусти `make validate` если доступно
2. Найди status mismatches, отсутствующие пары data↔wiki для approved/canon
3. Сверь термины с `meta/GLOSSARY.md`
4. Отчёт: список нарушений, без авто-правок канона без спроса
