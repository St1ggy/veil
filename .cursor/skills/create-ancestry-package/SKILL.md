# Создать Ancestry package

1. ID `ANC_*` в `game/player/ancestries/`
2. Обязателен `lore_targets` → существующий `RACE_*`
3. Секции MD: Lore, Design Goals, Gameplay Goals, Balance, Advantages, Disadvantages, Variants, Future Expansion
4. Без dice steps / trait numbers из core
5. Статус draft/research
