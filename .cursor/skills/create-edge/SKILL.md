# Создать Edge

1. `meta/ID_SCHEME.md`, `meta/game/QUALITY_GATE.md`, `meta/game/COMPATIBILITY.md`
2. ID `EDGE_*`; категория под `game/player/edges/{category}/`
3. YAML + MD из `game/_templates/edge.yaml`
4. Поля: design_notes, balance_notes, prerequisites, synergies, counterplay
5. Связь с лором через lore_targets/relations
6. Запрещено: reprint Edges из книг SWADE; числовые бонусы core
7. Статус draft/research
