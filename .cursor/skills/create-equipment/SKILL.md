# Создать Equipment

1. ID `EQ_*` в нужной категории `game/player/equipment/{category}/`
2. Шаблон `game/_templates/equipment.yaml`
3. Связь с TECH_/ART_/EVENT_ по смыслу
4. Без таблиц урона/брони из SWADE core
5. Статус draft/research
