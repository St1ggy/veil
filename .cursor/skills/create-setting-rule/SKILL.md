# Создать Setting Rule

1. Прочитай `meta/game/SETTING_RULES_POLICY.md`
2. ID `SR_*`; YAML + MD в `game/player/setting_rules/`
3. Укажи когда включать, какие сцены, зависимости лора
4. Добавь pointer в `game/systems/` при сквозной подсистеме
5. Без числовых триггеров core SWADE; статус draft/research
