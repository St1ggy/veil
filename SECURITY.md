# Security

This repository primarily contains creative writing and documentation tooling.

## Reporting

If you discover a vulnerability in CI scripts, generators, or dependency supply chain, open a private security advisory or contact the repository owner. Do not file public issues for exploitable tooling bugs.

## Scope

- Lore leaks are a content policy matter (`meta/SPOILER_POLICY.md`), not a CVE
- Do not commit secrets, API keys, or private campaign notes meant to stay offline
