# Контроль территорий

**ID:** `SR_TERRITORY_CONTROL`

## Назначение

Когда включать «Контроль территорий» за столом.

## Сцены

Какие конфликты и дилеммы открывает (DESIGN_PRINCIPLES §10).

## Зависимости лора

`CONCEPT_DOMAIN` и связанные статьи.

## Когда не использовать

Если сцена не касается соответствующей системы мира.
