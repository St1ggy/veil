# ADR-0003: Licensing

## Status

Accepted

## Context

Lore IP and tooling code have different reuse needs.

## Decision

- World content (`data/`, `wiki/`, `books/`, `game/`, `assets/` original art): All Rights Reserved (see root `LICENSE`)
- Tooling (`scripts/`, schemas, CI): MIT (see `LICENSE` dual notice)

Contributors grant the project owner rights to include contributions under these terms (`CONTRIBUTING.md`).

## Consequences

Public forks of lore require explicit permission. Tooling may be reused freely.
