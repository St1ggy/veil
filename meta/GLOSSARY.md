# Глоссарий

| Термин | ID | Определение |
|--------|-----|-------------|
| Эфир | `COS_ETHER` | Слой реальности: вероятности, идеи, архетипы. Сознание → Эфир → вероятность → материя. |
| Вуаль | `COS_VEIL` | Граница материи и Эфира. Ослабление с 2170. |
| Архетипы | `COS_ARCHETYPES` | Формы коллективного бессознательного; материализуются после Пробуждения. |
| Великое Пробуждение | `EVENT_GREAT_AWAKENING` | 2170: начало ослабления Вуали. |
| Третья мировая | `EVENT_THIRD_WORLD_WAR` | 2325: коллапс экономики, государств, орбиты и глобальной сети. |
| Звёздный Дождь | `EVENT_STARFALL` | Падения орбитальных объектов с ИИ, материалами, артефактами. |
| Вероятностная магия | `MAG_PROBABILITY` | Магия не ломает физику — меняет вероятность. |
| Эфирное Выгорание | `PHENO_ETHER_BURNOUT` | Цена магии: истощение, мутации, потеря памяти и др. |
| Вероятностный Распад | `PHENO_PROBABILISTIC_DECAY` | Рост ошибок техники под магическим давлением. |
| Принцип Arcanum | `CONCEPT_ARCANUM` | Взаимное давление магии и высоких технологий; возможны гибриды. |
| Нулевые Поля | `TECH_NULL_FIELD` | Антимагическая / стабилизационная технология Эгиды. |
| Мёртвый Интернет | `CONCEPT_DEAD_INTERNET` | Информационные следы Сети в Эфире. |
| Сетевые маги | `MAG_NETWORK` | Работа с Мёртвым Интернетом и следами данных. |
| Божественность | `CONCEPT_DIVINITY` | Состояние, не раса; достижима и обратима. |
| Домен | `CONCEPT_DOMAIN` | Фундаментальная концепция, к которой привязан бог. |
| Земля 2435 | `ERA_2435_PRESENT` | Текущая эпоха сеттинга. |

Новые термины добавляются сюда до широкого использования в каноне.

Публичная страница: `/{lang}/glossary` (данные зеркалятся в `web/src/data/glossary.ts`).
