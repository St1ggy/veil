# Глоссарий

| Термин | ID | Определение |
|--------|-----|-------------|
| Эфир | `COS_ETHER` | Слой реальности, связанный с вероятностями, идеями и архетипами. Сознание → Эфир → вероятность → материя. |
| Вуаль | `COS_VEIL` | Граница между материей и Эфиром, ослабевающая с 2170 года. |
| Архетипы | `COS_ARCHETYPES` | Формы коллективного бессознательного, способные материализоваться после Пробуждения. |
| Великое Пробуждение | `EVENT_GREAT_AWAKENING` | Событие 2170 года, с которого началось ослабление Вуали. |
| Третья мировая война | `EVENT_THIRD_WORLD_WAR` | Война 2325 года, приведшая к распаду глобальной экономики, государственных систем, орбитальной инфраструктуры и единой сети. |
| Звёздный Дождь | `EVENT_STARFALL` | Падение множества орбитальных объектов с ИИ, материалами и артефактами. |
| Вероятностное взаимодействие | `MAG_PROBABILITY` | Эфирологическое взаимодействие не нарушает законы физики, а меняет вероятность. |
| Эфирное Выгорание | `PHENO_ETHER_BURNOUT` | Цена взаимодействия: истощение, мутации, потеря памяти и другие последствия. |
| Вероятностный Распад | `PHENO_PROBABILISTIC_DECAY` | Рост частоты технических сбоев под воздействием интенсивного эфирологического взаимодействия. |
| Принцип Арканум | `CONCEPT_ARCANUM` | Взаимное давление эфирологии и высоких технологий, при котором возможно создание гибридных систем. |
| Нулевые Поля | `TECH_NULL_FIELD` | Технология эфирного подавления и стабилизации, применяемая Эгидой. |
| Мёртвый Интернет | `CONCEPT_DEAD_INTERNET` | Информационные следы Сети в Эфире. |
| Сетевые операторы | `MAG_NETWORK` | Специалисты, работающие с Мёртвым Интернетом и информационными следами. |
| Божественность | `CONCEPT_DIVINITY` | Состояние, а не раса; может быть достигнуто и утрачено. |
| Домен | `CONCEPT_DOMAIN` | Фундаментальная концепция, к которой привязан бог. |
| Земля 2435 | `ERA_2435_PRESENT` | Современная эпоха мира. |

Новые термины добавляются сюда до широкого использования в каноне.

Публичная страница: `/{lang}/glossary` (данные зеркалятся в `web/src/data/glossary.ts`).
