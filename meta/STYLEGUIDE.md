# Style guide

## Тон

Энциклопедия мира, не маркетинговый текст и не роман.

Предпочтительный порядок в разделе:

1. Определение / факт
2. Механизм или причина
3. Последствия для общества / игры
4. Открытые вопросы (если есть)

## Язык

- Primary: русский
- Имена собственные: кириллица в `title`; латиница в ID и при необходимости в `aliases`
- Избегать англицизмов там, где есть устойчивый русский термин (кроме канонических: Arcanum, Эфир как термин)

## Запрещено

- «Древнее зло пробудилось» без механики и последствий
- Магия как универсальный сюжетный клей
- Технологии без происхождения, производства и ресурсной базы
- Противоречие принципу Arcanum без явного гибридного объяснения

## Структура абзаца

Короткие абзацы. Списки — для перечислений фактов. Таблицы — для сравнений и чисел.

## Spoiler-маркеры в прозе

Секреты мастера не пишутся в публичных статьях. Если нужны — отдельный файл в `game/gm/` или блок с `spoilers: gm` во frontmatter всей статьи.
