# Compatibility

## Назначение

Границы совместимости с Savage Worlds Adventure Edition.

## Область ответственности

Что нельзя ломать в ядре; что выражается только через extension points.

## Связанные документы

- `meta/game/EXTENSION_POINTS.md`
- `meta/game/CHANGE_POLICY.md`


## Разрешено

- Ancestries, Edges, Hindrances, Arcane Backgrounds
- Powers **trappings** и сеттинг-риски (не список сил из core book)
- Setting Rules и подсистемы Veil
- Equipment, Vehicles, tables, generators

## Запрещено

- Переписывать математику бросков / инициативу / Benny economy ядра
- Копировать или близко пересказывать текст книг SWADE
- Вводить «вторую главную систему» поверх SWADE
- Публиковать числовые статы core powers как «наши»
