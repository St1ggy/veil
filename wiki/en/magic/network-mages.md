# Network Mages

## Overview

The global Internet is gone. But the Ether preserved its informational traces: the [[CONCEPT_DEAD_INTERNET|Dead Internet]].

Network Mages can:

- search for old data;
- read the memory of places;
- communicate with AI remnants;
- see informational traces;
- work through old communications networks.

## Cost

Like other magic, it brings neural strain and a risk of [[PHENO_ETHER_BURNOUT|Ether Burnout]].
