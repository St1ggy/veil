# Логичность

Любой элемент мира должен иметь объяснение. Если существует технология — должна существовать экономика, которая делает её возможной. Если существует государство — должно существовать общество, поддерживающее его существование. Если существует эфирологическое взаимодействие — должны существовать ограничения его применения.
