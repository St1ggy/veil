# Эфирологическая сеть

Эфирологическая сеть — распределённая инженерная система, объединяющая множество операторов, моделей взаимодействия и вычислительных комплексов для совместного выполнения задач.

Эфирологические сети являются основой современной высокоуровневой инфраструктуры.
