# Приложение C. Распределение ответственности

Жизненный цикл модели требует участия специалистов различных направлений.

Основные роли распределяются следующим образом.

| Роль | Основная ответственность |
| ------ | -------------------------- |
| Исследователь | Получение объективных научных данных |
| Инженер-проектировщик | Разработка архитектуры модели |
| Инженер-разработчик | Реализация проектной документации |
| Испытатель | Проведение инженерных испытаний |
| Сертифицирующий эксперт | Подтверждение соответствия международным стандартам |
| Оператор | Профессиональная эксплуатация модели |
| Инженер сопровождения | Поддержание работоспособности модели |
| Аудитор | Проверка соответствия международным требованиям |

Ответственность каждой роли ограничивается областью её профессиональной компетенции.

Передача ответственности между этапами жизненного цикла оформляется соответствующей инженерной документацией.
