# Приложение A. Основные категории специалистов

| Категория | Основная область деятельности |
| ----------- | ------------------------------- |
| Исследователь | Получение новых научных знаний |
| Инженер | Проектирование и разработка моделей взаимодействия |
| Инженер инфраструктуры | Создание и сопровождение крупных инженерных систем |
| Инженер безопасности | Анализ рисков и обеспечение безопасности |
| Инженер испытаний | Проверка моделей перед эксплуатацией |
| Инженер сопровождения | Поддержание моделей в течение жизненного цикла |
| Оператор инженерной системы | Эксплуатация инженерных систем |
| Инспектор | Контроль соблюдения стандартов |
| Аудитор | Независимая оценка процессов и документации |
| Руководитель проекта | Организация инженерной деятельности |
