# Приложение D. Классы энергетических объектов

| Класс | Назначение |
| -------- | ------------ |
| I | Локальное энергоснабжение отдельных объектов |
| II | Городские энергетические объекты |
| III | Региональные энергетические комплексы |
| IV | Национальные энергетические системы |
| V | Международная энергетическая инфраструктура |

Класс определяет требования к:

- резервированию;
- безопасности;
- мониторингу;
- обслуживанию;
- срокам восстановления.

Перечисленные требования являются обязательными и учитываются при проектировании, испытаниях и эксплуатации.
