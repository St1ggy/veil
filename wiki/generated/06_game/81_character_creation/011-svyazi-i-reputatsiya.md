# Связи и репутация

Каждый герой создаёт три связи: близкого человека, профессиональный контакт и организацию. Одна связь надёжна, одна требует взаимности, одна осложнена старым конфликтом. Дополнительно группа создаёт хотя бы одну общую связь, объясняющую совместную работу.

Репутация существует по областям. Герой может быть уважаем спасателями, неизвестен дипломатам и разыскиваться корпоративной службой. Всемирной шкалы известности нет.
