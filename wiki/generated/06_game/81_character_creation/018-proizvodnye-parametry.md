# Производные параметры

Шаг, Защита, Стойкость и Размер рассчитываются по обычным правилам системы «Дикие Миры» с поправками народа и снаряжения. Харизма не является отдельным параметром; отношение меняют Черты, Помехи, репутация и обстоятельства.

Языки следуют правилу сеттинга Несколько языков: герой знает Общий Международный и число дополнительных языков, определяемое половиной его Смекалки. Родной язык может быть одним из них либо отдельным культурным языком по решению группы. Для профессионального владения древним, эфирологическим или закрытым ритуальным регистром требуется соответствующая компетентность.
