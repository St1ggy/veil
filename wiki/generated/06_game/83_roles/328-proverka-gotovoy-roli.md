# Проверка готовой роли

Игрок должен назвать три типовые задачи, два способа Поддержка и три вещи, которые персонаж не умеет. Для каждого высокого Навыка указывается обучение. Для каждой Черта — событие или институт, давший возможность. Для Мистический дар — школа, наставник, Домен или нелегальный источник практики.

Если описание персонажа говорит «умеет всё понемногу», игрок выбирает конкретные к6 и принимает, что сложные задачи потребуют Поддержка. Если описание говорит «лучший специалист», один основной Навык и линия Черты должны иметь приоритет над широтой.
