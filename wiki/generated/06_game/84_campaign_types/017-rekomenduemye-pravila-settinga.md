# Рекомендуемые Правила сеттинга

Базовый тон использует Решимость, Творческий бой, Динамическая отдача для эфирологии, Несколько языков и Предел ранений. Жестокие повреждения подходит только для кампаний выживания и военной медицины. Герои не умирают уместно для героического тона, но не для хоррора аномалий. Благосостояние используется в торговой кампании; в остальных случаях достаточно обычных средств и организационного доступа.

Группа фиксирует выбранные Правила сеттинга до создания героев.
