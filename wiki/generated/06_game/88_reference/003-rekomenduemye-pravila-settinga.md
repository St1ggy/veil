# Рекомендуемые правила сеттинга

Основной набор: Решимость, Творческий бой, Динамическая отдача, Несколько языков и Предел ранений. Благосостояние включается для торговой кампании. Жестокие повреждения — только для согласованного сурового тона. «Рождённый героем» меняет доступ к Чертам и должен быть выбран до создания персонажей.
