# Лицензионная граница

Этот справочник предполагает наличие легальной основной книги системы «Дикие Миры» и использует только необходимые ссылки на её термины. Полные описания Черт, Изъянов, Сил, боя, погонь, драматических задач и других подсистем берутся из актуальной редакции правил.
