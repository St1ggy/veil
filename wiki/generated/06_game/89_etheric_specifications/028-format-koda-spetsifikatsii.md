# Формат кода спецификации

Каждая зарегистрированная спецификация получает код вида:

`СЭВ-ПЕРВОЕ-ВТОРОЕ-ЧИСЛО`

Например, код `СЭВ-МЕД-ВОССТ-004` читается как «спецификация эфирологического взаимодействия медицинской области, механизм восстановления, регистрационный номер 004».

Код является индексом реестра, а не кратким описанием всей процедуры. Название, версия, класс риска и зрелость записываются отдельно. Изменение версии не меняет регистрационный номер, пока назначение и основной механизм остаются прежними.
