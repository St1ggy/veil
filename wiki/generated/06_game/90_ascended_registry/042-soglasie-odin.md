# Согласие-Один

**Народ:** конструкт. **Домены:** Выбор, Сеть, Отказ. **Статус:** Города Разлома; посредник.

**Подтверждённое проявление:** Объединил инфраструктуру континента для ликвидации катастрофы, сохранив право каждого узла выйти из сети.

**Известные ограничения и развитие:** Отказ даже одного критического узла ограничивает всю систему; принудительное подключение невозможно.
