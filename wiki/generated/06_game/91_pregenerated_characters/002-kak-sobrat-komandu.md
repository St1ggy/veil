# Как собрать команду

Для универсальной группы выберите по одному герою, отвечающему за действия в опасной среде, исследование, социальное взаимодействие и поддержку. Пятый участник может усилить нужное направление. Для расследования особенно полезны следователь, информационный специалист и переговорщик; для экспедиции — проводник, инженер, медик и пилот; для спасательной истории — защитник, координатор, спасатель и логист; для политической игры — переговорщик, организатор, репортёр и инфильтратор.
