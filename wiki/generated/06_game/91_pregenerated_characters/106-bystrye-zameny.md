# Быстрые замены

Народ можно заменить, пересчитав только пакет физиологических особенностей. Профессию можно изменить внутри роли без бесплатной замены Навыков. Эфирную версию неоператора следует создавать через обычные ресурсы персонажа, а не добавлением сил поверх готовой сборки.
