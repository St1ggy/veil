# Перед игрой

- [ ] Согласованы жанр, границы и состав группы.
- [ ] У каждого героя есть причина участвовать.
- [ ] Подготовлены место, кризис и стороны.
- [ ] Есть не меньше трёх источников ключевой информации.
- [ ] Понятно, что случится при задержке.
- [ ] Под рукой карты, кубики и фишки.
