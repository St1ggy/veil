# Мира Лесная

**Крючок:** ищет источник болезни разумного леса.

- **Приземлённое объяснение:** Болезнь вызвана безопасным для людей удобрением, нарушившим обмен сигналами леса.
- **Чей-то замысел:** Разумный лес симулирует симптомы, чтобы остановить строительство через корневую сеть.
- **Неопределённое явление:** Каждый вылеченный участок передаёт болезнь дальше вместе с памятью о лечении.

**Игровая опора:** Драматическая задача; в центре сцены — Лечение к8, Естествознание к8, Выживание к6, Внимание к6.
