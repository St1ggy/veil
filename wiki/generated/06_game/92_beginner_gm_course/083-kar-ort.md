# Кар-Орт

**Крючок:** данные противоречат рассказам первых драконидов.

- **Приземлённое объяснение:** Противоречие объясняет земное наблюдение, неверно истолкованное ранними свидетелями.
- **Чей-то замысел:** Первые дракониды сознательно упростили рассказ ради безопасности переселенцев.
- **Неопределённое явление:** Данные надёжны, но позволяют утверждать лишь наличие неизвестного процесса, не иного мира.

**Игровая опора:** Погоня; в центре сцены — Наука к10, Исследование к8, Электроника к6, Общие знания к8.
