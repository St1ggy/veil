# Тала Медный Лист

**Крючок:** новый источник воды существует сразу в двух несовместимых кадастрах.

- **Приземлённое объяснение:** Кадастры используют разные определения источника и оба юридически корректны.
- **Чей-то замысел:** Разночтение создано намеренно, чтобы будущий спор остановил невыгодный проект.
- **Неопределённое явление:** Вода действительно поступает из двух направлений и меняет происхождение при измерении.

**Игровая опора:** Расследование с тремя источниками; в центре сцены — Убеждение к10, Исследование к8, Общие знания к8, Внимание к6.
