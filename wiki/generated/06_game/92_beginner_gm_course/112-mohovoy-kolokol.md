# Моховой Колокол

**Крючок:** семена из закрытого банка дают урожай с воспоминаниями прежних владельцев.

- **Приземлённое объяснение:** Семена хранят химические маркеры прежних условий, которые люди принимают за воспоминания.
- **Чей-то замысел:** Банк использовал незаконные когнитивные отпечатки владельцев для управления урожаем.
- **Неопределённое явление:** Растения сообщают разные эпизоды только тем, кто ухаживает за ними определённым способом.

**Игровая опора:** Расследование с тремя источниками; в центре сцены — Выживание к10, Наука к8, Ремонт к8, Общие знания к6.
