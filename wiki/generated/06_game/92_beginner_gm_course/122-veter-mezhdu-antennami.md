# Ветер Между Антеннами

**Крючок:** восстановленная антенна связалась с городом, которого нет на современных картах.

- **Приземлённое объяснение:** Название принадлежит старому району существующего города, исчезнувшему из современных карт.
- **Чей-то замысел:** Кто-то использует историческое имя как закрытый позывной нелегальной сети.
- **Неопределённое явление:** Ответ содержит текущую погоду и расписание города, местоположение которого ни один сигнал не позволяет определить.

**Игровая опора:** Драматическая задача; в центре сцены — Электроника к10, Ремонт к8, Атлетика к8, Внимание к8.
