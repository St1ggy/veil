# Майя Пятый Перрон

**Крючок:** получает расписание поезда, которого нет ни в одном реестре.

- **Приземлённое объяснение:** Сбой возник из-за тестового расписания, которое случайно подписали рабочим ключом.
- **Чей-то замысел:** Кто-то использует несуществующий поезд, чтобы заставить Майю открыть зарезервированный путь.
- **Неопределённое явление:** Состав появляется на датчиках только тогда, когда на перроне остаётся один человек.

**Игровая опора:** Диспетчерская драматическая задача; в центре сцены — Общие знания к8, Убеждение к8, Внимание к8, Электроника к6.
