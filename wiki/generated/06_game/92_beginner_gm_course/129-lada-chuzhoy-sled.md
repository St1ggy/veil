# Лада Чужой След

**Крючок:** пропавшие звери возвращаются и приносят вещи одного незнакомца.

- **Приземлённое объяснение:** Звери тащат вещи из открытого склада, где недавно работал пропавший смотритель.
- **Чей-то замысел:** Незнакомец обучил животных собирать предметы, чтобы через Ладу передать маршрут.
- **Неопределённое явление:** Принесённые вещи принадлежат человеку с разными биографиями в каждом реестре.

**Игровая опора:** Поиск по меняющемуся следу; в центре сцены — Внимание к10, Выживание к8, Скрытность к8, Атлетика к8.
