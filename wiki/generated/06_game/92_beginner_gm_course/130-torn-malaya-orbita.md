# Торн Малая Орбита

**Крючок:** получает законный груз, который становится легче при подъёме.

- **Приземлённое объяснение:** Контейнер наполнен подъёмными ячейками, ошибочно оформленными как обычная тара.
- **Чей-то замысел:** Заказчик проверяет, сможет ли Торн незаметно вывести экспериментальную технологию из порта.
- **Неопределённое явление:** Масса груза уменьшается только над местами, которых нет на навигационной карте.

**Игровая опора:** Транспортное испытание; в центре сцены — Пилотирование к10, Ремонт к8, Внимание к8, Навигация к6.
