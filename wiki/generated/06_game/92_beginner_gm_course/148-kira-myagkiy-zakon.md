# Кира Мягкий Закон

**Крючок:** подопечный получает документы на имя, которое видел только во сне.

- **Приземлённое объяснение:** Имя автоматически предложено из закрытого семейного черновика, синхронизированного с реестром.
- **Чей-то замысел:** Сотрудник ведомства создаёт фальшивые личности и через Киру ищет для них настоящих поручителей.
- **Неопределённое явление:** Документ становится действительным только после того, как подопечный засыпает.

**Игровая опора:** Социальное расследование; в центре сцены — Убеждение к10, Общие знания к8, Лечение к6, Исследование к8.
