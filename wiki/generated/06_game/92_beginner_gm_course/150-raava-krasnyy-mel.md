# Раава Красный Мел

**Крючок:** учебный сценарий начинает в точности повторяться в городе.

- **Приземлённое объяснение:** Городская служба скопировала учебный план Раавы для реального реагирования.
- **Чей-то замысел:** Кто-то ставит происшествия по её сценарию, изучая действия обученных граждан.
- **Неопределённое явление:** Случайные участники произносят реплики из закрытой версии учебного материала.

**Игровая опора:** Защита гражданских; в центре сцены — Драка к10, Атлетика к8, Убеждение к8, Внимание к8.
