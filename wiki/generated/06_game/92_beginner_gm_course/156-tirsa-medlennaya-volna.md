# Тирса Медленная Волна

**Крючок:** целый квартал видит один сон после каждого её сеанса.

- **Приземлённое объяснение:** Общий сон вызывает нелегальная звуковая реклама, работающая ниже порога пробуждения.
- **Чей-то замысел:** Кто-то собирает через сеансы Тирсы одинаковые образы, чтобы превратить их в политический символ.
- **Неопределённое явление:** Во сне квартал видит решения, которых никто из жителей ещё не предложил.

**Игровая опора:** Кризисная социальная сцена; в центре сцены — Убеждение к10, Лечение к8, Внимание к8, Общие знания к8.
