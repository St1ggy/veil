# Линза-Море

**Крючок:** батискаф получает ответ на вопрос, который экипаж не передавал.

- **Приземлённое объяснение:** Автономный модуль распознавания речи преобразует шум экипажа в ошибочный запрос.
- **Чей-то замысел:** Удалённый оператор проверяет реакцию исследователей, скрывая управляющие команды среди ответов.
- **Неопределённое явление:** Батискаф отвечает на вопрос, который один член экипажа сформулировал только мысленно.

**Игровая опора:** Глубоководное исследование; в центре сцены — Наука к10, Пилотирование к8, Электроника к8, Внимание к10.
